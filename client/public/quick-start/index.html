Turn a tool photo into a Gridfinity bin

Pocketry traces tool outlines from photos and turns them into pockets for printable bins. Your photo and editable design stay in your browser.

Open Trace Open Bin Start with a sample project

  1. Photograph and scale the tool

    Take a photo from directly above on a plain, contrasting background. Open the original PNG, JPEG, or WebP in Trace. For a detected calibration sheet or measurement aid, choose Correct perspective & use scale or Correct perspective & use aid scale. If Pocketry finds the paper corners, confirm A4 or US Letter and adjust the handles before applying. You can also choose Set scale, mark a known distance, and enter it in millimeters. Check the result against a real measurement.

  2. Trace the outline

    Choose Region → Set region and box the tool. Use Tool edges · white sheet on white paper or Color contrast for other backgrounds. Inspect the result with Edit outline. When it follows the tool, choose Add to Bin.

  3. Arrange the pockets

    Set Bin size and arrange the pockets in Layout. Set each pocket’s depth and add finger access where you need room to lift the tool. For a standalone bin, choose Construction → Base & mounting → Bottom → Flat bottom.

  4. Check the fit and export

    Use Check fit to export a thin fit-check STL. Print it at 100% scale and try your tools in the openings. Review pocket depth and floor thickness in 3D. When the design is ready, choose Export → Save 3MF or Save STL. Use Project → Export project to keep an editable backup.

The photo-to-bin tutorial on GitHub walks through the Wolfbox example with screenshots.
