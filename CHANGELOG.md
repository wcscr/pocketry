# Changelog

Notable user-visible changes to Pocketry, organized by application version with
newest versions first. The version in `package.json` is also shown on About.
See [Versions and update history](README.md#versions-and-update-history) for the
release process.

## Unreleased

## 1.0.0 — 2026-09-26

This is the first documented version baseline, using the existing package
version. Earlier development was not assigned release versions; the highlights
below summarize the application at this baseline rather than inventing past
version numbers.

### Added

- Display the application version on About, with a link to this version history.
- Introduce this changelog and a documented process for future version updates.

### Existing capabilities

- Trace tool photos into editable outlines, including interior holes, and
  calibrate dimensions with manual measurements or printable reference aids.
- Design Gridfinity and flat bins with custom pockets and footprints, finger
  access, adjustable solid fill height, and preview/material colors.
- Export fit checks, STL and single- or multi-color 3MF models, plus SVG and DXF
  outlines and shadow-board layouts.
- Save projects in the browser, reuse shapes, undo edits, and import or export
  editable project backups and project libraries.
- Browse sample projects with editable designs, print models, and finished-bin
  photos; use responsive Trace and Bin workspaces on smaller screens.

### Recent improvements included

- Faster previews for complex bins while retaining feedback during editing.
- Restore saved project names and recover newer working copies of named projects;
  add direct Library navigation and save imported projects to the browser library.
- Consolidate bin and shadow-board exports, and open matching color controls from
  the preview legend.
- Improve Autodesk Fusion DXF compatibility and detection of small calibration
  markers; add printable paper calibration aids.
