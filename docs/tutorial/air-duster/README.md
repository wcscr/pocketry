These copies have their original display orientation applied to the pixels. EXIF,
XMP, ICC profiles, MPF/embedded secondary-image metadata, JPEG application segments,
and comments have been removed. The originals are unchanged. The clean copies
retain the full displayed resolution and were saved as high-quality JPEGs.

The narrow pocket along the left edge of the reference layout is for the USB
cable. In the original editable project, the angled nozzle was named “USB Cable”
and the cable pocket was named “Corner Adapters”; the tutorial corrects these
labels without changing their saved outlines.
