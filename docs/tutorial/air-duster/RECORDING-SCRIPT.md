# Air duster tutorial — recording script

Revised September 15, 2026, to incorporate the latest feedback.

## Recording requirements

- Record headlessly with Playwright in an isolated browser.
- Use continuous UI motion, a visible cursor, short American English captions, and no audio.
- Keep the finished video under 10 minutes; label accelerated portions.
- Follow one new project from photo imports through actual downloads.
- Retain each numbered segment, the original recording, and project checkpoints for replacement edits.
- Use only the three real tool photographs. Create the USB cable pocket with **Finger access**.
- Complete each tool's contour in its first **Edit points** session. Show removal, movement, and addition of points in the actual UI. Do not return to contour editing during the later sizing steps.
- Direct viewers to the real tool, caliper measurements, and printed fit checks for all shape, size, clearance, and depth decisions. All numeric values shown are examples for these tools.
- Show one set of ruler measurements and X/Y size corrections, followed immediately by fit-check export.
- Include a clearly labeled placeholder for the future photo showing the fit check with real tools.

## 00–01 — Photos and new project

Show `air-duster.jpg`, `adapter-stack.jpg`, and `angled-nozzle.jpg`. Highlight the calibration markers on the first photo. Preserve the real shadows in the photographs. Transition to **Bin → Project**, create and save **Air Duster Tutorial**, then open **Trace**.

Captions:

- “Start with photographs of the tools you want to trace.”
- “Photograph tools on the provided templates to make scaling easier.”
- “Here are the photographs we took of the air duster, adapters, and angled nozzle.”
- “Some of the shadowing isn’t ideal. We’ll correct it when editing the outlines.”

## 02–04 — Trace and finish each contour once

For each photo, apply the detected calibration-sheet correction and draw a region around the tool. Keep interior holes off. Set sensitivity before editing; the adapter photo needs adjustment to recover reflective edges. Set Detail and Smoothing before entering **Edit points**. Use a zero Trace margin for the example.

In one continuous editing session per tool, remove extra points, move misplaced points, and add missing corners. Complete the entire outline before **Add to bin**. Name the three tools **Air Duster**, **Adapters**, and **Angled Nozzle**. After the nozzle, choose **Add and arrange**.

Captions:

- “Print the calibration sheet at 100% and check its 100 mm reference bar.”
- “Follow the physical edge of the tool. Shadows and reflections can distort the trace.”
- “Right-click to remove extra points. Keep the corners that define the real tool.”
- “Drag points to refine the shape, using the real tool and its measurements as your guide.”
- “Click an edge to add a needed corner, then drag the new point into position.”

## 05–06 — Bin and USB cable pocket

Set full 42 mm grid pitch, 4 × 4 cells, 6.5u height, and **Keep bin size fixed**. Use solid fill and a stacking lip, with magnet and screw holes off. Drag the three tools into the layout and demonstrate position and rotation controls. Apply 1 mm top rounding, 1.2 mm bottom fillets, and 1 mm contour corner rounding.

Open **Finger access → Add hole**. Rename the new opening **USB Cable**, choose **Slot**, **Flat bottom**, and **Flat ends**. Enter the example width 17.44 mm, length 103.59 mm, and depth 37.3 mm. Round its corners and edges, rotate it upright, and position it at the left side of the bin.

Captions:

- “In addition to the photos, we’ll create a pocket for the USB cable using Finger access.”
- “Measure the coiled cable, then set the slot’s width, length, and depth. Calipers help with depth.”

## 07 — Measure once and adjust X/Y scale

Select the duster and use the Layout ruler once at each of three locations: vertical span, handle width, and head width. Keep the endpoints and actual reading visible. Explain that viewers compare these with measurements of their real tool.

Exit the ruler. Demonstrate linked proportions, then unlock when X and Y need different corrections. Enter the following example overall dimensions, showing the resulting scale percentages. Do not return to the ruler or contour editor in this demonstration.

| Tool | Width × length before rotation |
| --- | --- |
| Air Duster | 87.83 × 145.57 mm |
| Adapters | 36.74 × 113.32 mm |
| Angled Nozzle | 45.43 × 52.75 mm |

Captions:

- “Measure the real tool with calipers. Compare its length, handle width, and head width with the outline.”
- “Keep proportions links width and length. Unlock it when the X and Y corrections differ.”
- “Use your measured dimensions to size the other tools. These values are for this example.”

## 08–09 — Export and try the fit check

Immediately open **Check fit**. Choose **Tool outlines**, set 1.2 mm thickness, and complete the real export confirmation and download. Explain that this mode checks the three photographed tools. Also export **Full surface** to include the USB cable pocket created with Finger access. Show the completed files in the browser's download list.

Show a neutral card labeled **PLACEHOLDER / Fit-check photo / Photo with the real tools to be added**. This is the replaceable insert for the user's future physical fit-check photo.

Captions:

- “Export a thin fit check now, before committing to the full bin.”
- “Tool outlines uses less material to check the three photographed tools.”
- “Choose Full surface to include the USB cable pocket created with Finger access.”
- “The fit-check files are saved. Print at 100% scale and try the real tools.”
- “Place the real tools in the printed fit check. Use the fit and your measurements to guide adjustments.”
- “If needed, adjust the contour, size, or clearance and print another fit check.”
- “A thin fit check tests the openings. Measure pocket depth and tool seating separately.”

## 10–11 — Depth, lifting scoops, and colors

Show the caption below while adjusting pocket depths. Start the duster at 39 mm for the later warning demonstration; set adapters and nozzle to 34 mm. Add an elongated curved-bottom lifting scoop and a round scoop at the nozzle.

**Required caption:** “Adjust pocket depth based on measurements of each real tool. Use calipers for accurate depth measurements.”

Set a gray body, black pocket floors and rim, 0.6 mm floor-color thickness, and 1.25 mm rim-color thickness. Expand the floor-color warning and follow its **Edit pocket** action. Reduce duster depth to 38.5 mm, show the remaining floor increase to 5.8 mm, and wait for the warning to clear.

Caption: “The warning clears. The tool sits 0.5 mm higher; check that seating depth.”

## 12–13 — Inspect and save

Orbit and zoom the completed bin. Open **Cross-section View**, enable the cut, inspect the duster's floor, then restore the full model and wait for rebuilding to finish.

Demonstrate final export with an editable project backup and show the actual completed files. Physical fit is a prerequisite for the viewer's full-bin print; this recording does not claim a physical fit test has already passed.

Captions:

- “Cross-section View helps inspect the interior. The exported model remains whole.”
- “After the real tools fit and pocket depths are checked, export the full bin.”
- “Save the finished bin and an editable project backup.”
- “Keep the editable project with the print file. Check the slicer preview before printing.”
