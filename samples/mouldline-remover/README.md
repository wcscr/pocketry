# Citadel Mouldline Remover

A fitted 17.5 mm-deep tool pocket with a rounded finger-access scoop beside the handle.

- **Size:** 1 × 4; 3.5u. Grid cells are 42 mm; one height unit is 7 mm, before the stacking lip.
- **Base:** Gridfinity.
- **Print model:** [mouldline-remover.3mf](mouldline-remover.3mf).
- **Editable project:** [mouldline-remover.pocketry.json](mouldline-remover.pocketry.json).

[How to open, edit, and print](../README.md#using-a-sample).
