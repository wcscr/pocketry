# AGENTS.md

**`CLAUDE.md` is the single source of truth for this repository.**

All agents (Codex, GPT-based tools, or any other AI) must read `CLAUDE.md` in full
and treat it as authoritative — it supersedes anything in this file.

These are public contributor instructions. Follow `CLAUDE.md` for optional
`CLAUDE.local.md` or `AGENTS.local.md` preferences; keep local files private.

**Attribution:** preserve human authorship. Outside contributions with material
AI assistance include tool `Co-Authored-By` credit as described in
`CONTRIBUTING.md`. Existing standing AI acknowledgments may cover maintainer
work without repeated commit or PR bylines. Agents cannot accept the CLA.

**Verification runs locally.** Follow the local-only verification policy in
`CLAUDE.md`; do not enable or trigger GitHub CI for routine updates.

`CLAUDE.md` covers:
- Project overview and objectives
- Repository structure
- Runtime and dependency management
- Build, test, lint, and docs commands
- Code conventions and architecture patterns
- Agent working principles and task flow
- Guardrails and human oversight requirements
