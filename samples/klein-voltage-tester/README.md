# Klein voltage tester

A narrow tool bin with a shaped voltage-tester pocket and finger access.

- **Size:** 1 × 4; 4u. Grid cells are 42 mm; one height unit is 7 mm, before the stacking lip.
- **Base:** Gridfinity.
- **Print model:** [klein-voltage-tester.3mf](klein-voltage-tester.3mf).
- **Editable project:** [klein-voltage-tester.pocketry.json](klein-voltage-tester.pocketry.json).
